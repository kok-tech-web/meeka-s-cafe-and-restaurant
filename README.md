# 🍽 MEEKA's Café and Restaurant

A full-stack website for **MEEKA's Café and Restaurant** — built to bring the restaurant online with a beautiful customer-facing website and an internal staff management system.

## 🌐 Customer website pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Landing page with hero, popular dishes, and signature combos |
| Menu | `menu.html` | Full menu — starters, mains, signature combos, café |
| Reservation | `reservation.html` | Book a table by date, time, and party size |
| Reviews | `reviews.html` | Star ratings and written customer reviews |
| Virtual tour | `tour.html` | Photo gallery and video walkthrough of the restaurant |
| Jobs | `jobs.html` | Open positions and job application form |
| Contact | `contact.html` | Phone, location, map, and message form |

## 🚀 Running locally

1. Clone the repo:
   ```bash
   git clone https://github.com/kok-tech-web/meeka-s-cafe-and-restaurant.git
   ```
2. Open the folder in VS Code
3. Right click `index.html` → **Open with Live Server**

No installations needed for the frontend — it runs straight in the browser.
